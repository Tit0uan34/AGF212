The Tellbreen files are the raw copy of the files we created when measuring 
the stake positions on Tellbreen and Blekumbreen. 
As you can read in the manual for using the 
leica infinity software (https://unisvalbard.github.io/gnss-compendium/leica_infinity.html) 
you should only need the .m00 file.

For the post kinematic processing we used base data provided by kartverket, the data can be found here 
https://drive.google.com/drive/folders/1DZXu_cIY6woxOhbHfrxSH70sTH3Qrx3s?usp=sharing
